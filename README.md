# Gemini English Learning Skills (British English)

A comprehensive English learning skill set for Gemini, designed around four core areas:

- **Speaking** (with video/podcast retelling module)
- **Vocabulary**
- **Listening**
- **Grammar**

All skills use **British English** conventions and vocabulary.

These prompts are built for practical daily use. They help the learner improve through realistic conversation, short exercises, contextual vocabulary, listening tasks, and grammar drills.

## Key features

### Speaking Coach (Enhanced)

**Core module**: Daily conversation practice
- realistic dialogue topics
- feedback on grammar, word choice, naturalness
- useful sentence patterns
- confidence building

**New module: Video & Podcast Retelling**
- personalised video/podcast recommendations based on your interests
- watch/listen and retell in your own words
- receive feedback on:
  - comprehension
  - fluency and naturalness
  - vocabulary usage
  - grammar accuracy
  - communication clarity

### Vocabulary Builder
- high-frequency, practical words
- British English spellings and conventions
- contextual examples
- collocations and phrasal verbs
- spaced repetition reviews

### Listening Practice
- short realistic dialogues
- British accent and natural speech
- key vocabulary and comprehension questions
- answer explanations
- mini listening challenges

### Grammar Master
- simple, practical explanations
- common learner mistakes
- British English grammar rules
- practice exercises with answer keys
- takeaway patterns for reuse

## How to use with Gemini

You can paste the contents of a skill file into:

- Gemini App system instructions
- custom prompt presets
- a chat assistant role setup
- a saved prompt template in your workflow

### Example usage

Open Gemini and paste the contents of a skill, or give these instructions:

```text
Use the speaking coach skill from this repository.
Focus on British English conventions.
Start with a conversation topic.
```

or

```text
Use the video & podcast retelling module from the speaking coach skill.
Recommend a video about [your interest].
I'll watch it and retell the content.
Then give me feedback using the speaking practice format.
```

## Recommended learning loop

**Daily routine (30–45 minutes)**:

1. **Speaking** (15 mins): conversation or video/podcast retelling
2. **Vocabulary** (10 mins): 5–8 new words
3. **Listening** (10 mins): one short dialogue
4. **Grammar** (5–10 mins): one grammar point

**Weekly rotation**:

- Monday: vocabulary + speaking (conversation)
- Tuesday: listening + grammar
- Wednesday: speaking (video/podcast retelling)
- Thursday: vocabulary review + listening
- Friday: grammar + speaking (conversation)
- Weekend: review all four areas
